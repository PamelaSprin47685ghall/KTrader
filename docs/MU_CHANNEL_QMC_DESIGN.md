## 0. 结论先行

1. **代码事实修正**：μ 通道的**前缀嵌套（nesting）已经存在于实现中**——每层从同一 `m_seed` 重建 MersenneTwister（quadrature.jl:600），`draw_mu` 的 rng 消耗序列与 M 无关（posterior.jl:887-907），故 M2 层的前 M 个 μ draw 与 M 层逐位相同（文档亦如此声称：quadrature.jl:290-297、:543-545）。因此「层间独立重洗」不是当前事实。
2. **真正的缺口**：μ 通道是 **iid MC 驱动**（固定 seed 的顺序流），而非 QMC/RQMC 驱动——收敛速率 M^{-1/2}，A 序列可以非单调（相邻两级是两个不同样本量下最优解的差，每级修正方向随机）。反弹 4.75× 与 MC 噪声形态一致；RQMC 的平滑收敛（如 d/z 通道）不会如此。
3. **策略落点是速率而不是嵌套**：把 μ 通道从「MC 序列」升级为「RQMC 点驱动」（含协方差谱排序以控制有效维度）——这才是「可收敛的积分结构」。仅仅（再次）确认前缀嵌套不能消除 M^{-1/2} 波动。
4. **推荐顺序**：先做**方差归因实验**（E1/E2，成本低、决定是否值得大改）；若 μ 贡献主导，实施 **b′（μ 通道 QMC 化 + 谱排序 + 逐分量 inverse-CDF）**；c（方差缩减变体）作为 b′ 的组成部分而非独立路线。
5. **同时登记（不预判）**：若 μ 通道 QMC 化后 A 仍在预算内不可达，则「A 判据（D-064 证书 A）在弱信号/μ 主导日期的适用性」应作为 SPEC 议题评估（第 6 节）。

## 1. μ 通道实现与数学形态（file:line）

### 1.1 抽样驱动结构（quadrature.jl）

- `predictive_rqmc_source.gen(M, rule, mu_rng)`（:345-373）：每场景 s：
  - μ：`mu_mode_s = draw_mu(post, xt, mu_rng)`（:350）；
  - d：rule 点第 1 维 → 离散 inverse-CDF（:353-354）；
  - z 行：rule 点第 2 维 → floor 变换（:356-357）；
  - ε = V_t(d)^{1/2}·z、y_R、u_R、r_R、gross（:358-369）。
- 每层重建：`solve_layer(M)` 内 `src.gen(M, opt_rule, MersenneTwister(m_seed))`（:600）；audit 用 `MersenneTwister(am_seed)`（:671）。
- 嵌套声明：每层从同一 seed 重建流 → 前 M 个 draws 与上一层逐位相同（:290-297、:543-545）。

### 1.2 matrix-t draw 的数学形态（posterior.jl:887-907）

```
r = rand(rng)                       # 节点 k 抽样（按 alpha_weights 离散 inverse-CDF）
z = L.L * randn(rng, N)             # L = cholesky(Symmetric(c.S_alpha))（:903）
g = rand(rng, Chisq(nu))            # 卡方
μ = μ̂_k + (sqrt(ck/nu) / sqrt(g/nu)) .* z
```

- 条件分布：μ | data ~ t_ν(μ̂_k, (c_k/ν)·S_alpha)，c_k = x_tᵀ A_k x_t（V_solve）；
- L Lᵀ = S_alpha（N×N）；**谱结构**：S_alpha 的特征值衰减决定 μ 方差的主方向（场景 8 归因：within cov eigmax=2.03e6，主因子 x'Vx=23330 × S_alpha eigmax=22.65——archive/evidence/gate0_innovation_attribution_20261010/）；
- 每次 draw 消耗的 rng 序列：rand×1 + randn(N) + rand(Chisq)×1——**与 M 无关**，故前缀嵌套成立；
- ν = n+1−N（G7 绑定）；ck 为标量；节点 k 的变长 while 循环只消费一个 rand（:891-897）。

### 1.3 嵌套 vs QMC：两个概念的精确区分

| 概念 | 现状 | 作用 |
|---|---|---|
| 前缀嵌套（同 seed 重建） | **已实现**（:600/:671/:290-297） | 消除「层间重洗」额外噪声；M2 前 M 个 μ 样本与 M 层逐位相同 |
| QMC 驱动（低差异点） | **未实现**（μ 通道为 iid 顺序流） | 收敛速率从 M^{-1/2}（MC）提升到接近 M^{-1}（RQMC） |

A 反弹的证据意义：在**已嵌套**前提下 A 仍可非单调——因为 A 度量的是两个不同样本量下最优解的差，μ 的 iid 采样误差 O(M^{-1/2}) 使序列波动。嵌套消除的是「重洗」噪声，不消除「采样」波动。**这是本设计的事实基础修正。**

## 2. 候选对比

| 候选 | 数学对象 | 速率预期 | 实现面 | 证书/判据影响 |
|---|---|---|---|---|
| (a) 前缀嵌套 MC（现状确认） | 不变 | M^{-1/2}（不变） | 已实现；仅需测试锚 | 无 |
| (b) μ 并入 QMC 维度（扩方向数表；dim=2+μ 维） | 积分对象不变；μ 样本由随机化 net 驱动 | 低有效维时接近 M^{-1} | 中-大：方向数表扩展、inverse-CDF、语义复审 | A/B/C 不变；需 SPEC 复审「μ 通道 QMC 化」语义 |
| (c) 方差缩减变体（谱排序、CRN、antithetic） | 不变 | 降常数/降有效维；单独不改变主速率 | 小-中（谱排序可并入 b） | 无（谱排序只是维度次序，不截断） |
| (d) 组合：b + 谱排序 (+ c 的 CRN 保持) | 同上 | 低有效维 + 低差异 → 最优先收 | 大（分阶段） | 同上 |

逐项评估：

**(a)** 已实现。单独不能消除 M^{-1/2} 波动；保留为「已嵌套」的事实基线（E2 锚），不作为修复路线。

**(b)** 关键问题：μ 的随机自由度 = 节点 k（离散 1 维）+ z（N 维标准正态）+ g（Chisq 1 维）。QMC 化的自然映射：
- 节点 k：1 维离散 inverse-CDF（与 d 通道同式）；
- z：N 维逐分量 inverse-CDF（z_i = Φ^{-1}(u_i)）——需要 N 个 QMC 维度；
- g：1 维 inverse-CDF（Chisq CDF 数值可算）；
- 合计 dim = 2（d+z 行）+ 1（节点）+ N（z）+ 1（g）= N+4。
- **N=1/2 可行**（dim 5-6，方向数表可扩）；**高 N 退化**：dim 大、Sobol 高维效率降——缓解手段 = **谱排序**（把 S_alpha 的特征基作为 z 的坐标，令 QMC 前几维驱动最大方差方向；线性正交变换不改变 N(0,I) 分布，不截断数学）→ 有效维度 ≈ 谱衰减的有效秩 k_eff，通常远小于 N。
- 语义要点：QMC 化的 μ 样本不是 iid，而是随机化低差异 net 上的变换值。RQMC 的无偏性（对 scramble 随机化求期望）与收敛性对**有界变差（或有界 Hardy-Krause 变差）**的变换成立；`Φ^{-1}` 在 [0,1] 端点无界——需要截尾处理（数值 floor）与 SPEC 复审。这是本候选最大的语义风险点，必须显式论证。

**(c)** 谱排序 = b 的组成部分（降低有效维度、不截断）。CRN = 现状的每层同 seed（保持）。Antithetic：μ 配对（u, 1−u）可降一阶矩方差，但破坏前缀结构、收益对非线性 Kelly 解不确定——评估后不推荐（登记）。

**(d)** = b + 谱排序。分期：先扩方向数表支持 dim = k_eff+4（或先支持 N=1/2 的日期），谱排序作为第一步（零依赖、收益可单测）。

3. 证书/判据全部原样；A 序列作为验收证据。

### 3.2 实现规格（草案，待 E1/E2 后定稿）

1. 规则扩展：`SobolOwenRule` 的 dim 上限从 2 扩到 2+N+2；方向数表 `_SOBOL_DIRV` 用 Joe-Kuo 前若干维（需验证递推实现与 net 性质；或引入标准方向数生成算法——不引外部依赖的约束下自实现）。
2. `predictive_rqmc_source.gen` 的 μ 分支：
   - 谱排序：对每节点 k 的 S_alpha 做 eigen 分解（或与 chol 复用），令 z 的坐标 = 特征基（正交变换 z' = Qᵀz 保持 N(0,I)）；
   - 逐分量 inverse-CDF：z_i = Φ^{-1}(u_i)（标准正态）；g = Chisq^{-1}(u)；节点 = 离散 inverse-CDF；全部由 rule 点驱动；
   - μ = μ̂ + (√(ck/ν)/√(g/ν))·L·z（L 与 z 的基一致）。
3. 语义复审点（SPEC）：μ 通道 QMC 化的语义（epistemic 不确定性以随机化 net 驱动）+ Φ^{-1} 端点截尾的数值 floor（须 floor→0 refinement 证据）；与 D-060 红线（μ 通道 epistemic、innovation aleatoric）不冲突。
4. fail-loud/确定性：无新 fail 路径；同 seed 逐位可重放；A/B/C 判据不变。

## 6. SPEC 议题登记（评估，不预判）

**「A 判据（D-064 证书 A）在弱信号/μ 主导日期的适用性」**：

- 事实链：A = ‖w_2M − w_M‖₁ 在 μ 主导日期由 μ 的采样误差驱动（O(M^{-1/2})）；外推 M_need ≈ 3.6e5 ≫ max_scenarios=512（现状）。
- 两种可能立场（均需 SPEC 评估）：
  (i) **A 慢是真实不确定性信号**：弱信号日 w 对 μ 先验不确定敏感 → 该日的决策本身在预算内不可稳定 → fail-loud（D-067）是诚实行为，多日链的可行性需要在「弱信号日」层面接受 fail 或另定决策语义；
  (ii) **A 的度量与目标不匹配**：A 是权重 L1 稳定性，而决策质量由目标值（B_opt/B_audit）与决策效用决定——在 μ 主导日期，权重可能不可稳定而目标值稳定（或反之）；判据组合的权重需按日期的信噪结构重新评估。
- 本设计不预判；只登记事实、外推与两条候选立场。任何调整须走 SPEC；不得以回测/预算为由改判据。

## 8. 节点选择 QMC 化（NODE-QMC-1；2026-10-10，通道分解后设计）

### 8.1 通道分解事实（A_channels_summary.md）

- **node 固定 → A 下降 34.7×**（2.238e-2 → 6.459e-4）；z 固定 → 收敛（@128）；chisq 固定 → 分布崩（排除该手段）。
- 结论：当前 A 的主导可缩减项 = mu 通道里**节点选择的纯 MC 离散抽样**（r = rand(mu_rng)）；z 通道的现状（前 2 主方向 QMC + 其余 MC）已不是瓶颈。

### 8.2 代码现状（file:line）

- _draw_mu_qmc（quadrature.jl:262-292）：节点选择 = r = rand(mu_rng) + 顺序累加 while（:265-271）——一阶 MC 离散抽样，逐场景独立、M^{-1/2} 波动。
- mu_pts（:411-413）= rule_points(SobolOwenRule(2, _mu_rule_seed(rule.seed)), M)，2 维全部用于 z 的前 2 主方向（:418 的 u_z1/u_z2）；**节点未 QMC 化**。
- SobolOwenRule 支持 dim 属于 {1,2}（:178-179），dim=1 复用 _SOBOL_DIRV[1,:]（van der Corput 方向数，V[1,k]=2^{32-k}）——**无需扩展方向数表**。

### 8.3 设计 a（推荐）：独立 1 维低差异序列驱动节点

- 规则：node_rule = SobolOwenRule(1, _mu_node_rule_seed(rule.seed))，其中 _mu_node_rule_seed(s) = s ⊻ 0x3C6EF372FE94F82B（任意确定常数；避开 _MU_QMC_SEED_XOR / audit_seed / _default_mu_seed 三个既有常数）。
- 抽样：node_pts = rule_points(node_rule, M)（M×1）；_draw_mu_qmc 的节点改为离散 inverse-CDF：cw_n = cumsum(post.alpha_weights)；k = min(searchsortedfirst(cw_n, u_node), length(cw_n))——与 while 版对同一 u 值**逐点等价**（都是第一个 cumsum ≥ u 的索引；min 截断防 u=1 越界）。
- 性质：
  - **嵌套**：每层同 seed 重建 node_rule → 前 M 点逐位相同（与 d/z 通道同机制）；
  - **audit 独立**：gen 收到的 rule 是 opt 或 audit（seed 已不同），再异或同一常数保不等 → 两套节点点列独立随机化；
  - **无偏**：1 维 scrambled Sobol 是 [0,1) 均匀的随机化低差异点列；离散 inverse-CDF 是单调阶梯变换（有界变差），RQMC 积分一致收敛；scramble 随机化下每点 k 的边际 = alpha_weights（期望意义）；
  - **确定性**：点列与变换均确定、无新增 RNG；
  - **零方向数表需求**：dim=1 已在现有构造覆盖（这解决了方案 c 的来源问题）。

### 8.4 方案 b/c

- **b（复用现有 2 维的某一维给节点）**：不推荐——同一 net 的维间相关会同时驱动 z 与节点（人为耦合），且维数不足（z1、z2、节点共 3 个一维需求）。
- **c（扩 Sobol 到 3 维）**：方向数来源不可得（Joe-Kuo 官方表不在本机；凭记忆内联违反证据纪律）——**登记为风险项，不采用**；a 不需要它。

### 8.5 z / chisq 通道（登记）

- z 通道：分解显示 z 固定后 @128 收敛——**已非瓶颈**；进一步缩减（把 z 的其余 N−2 维也 QMC 化）登记为可选项，待节点修复后若 z 重新成为主导再评估。
- chisq：固定会改变分布（分解已排除）；唯一合法路径是 1 维 inverse-CDF QMC 化（Chisq 逆 CDF 可得）——非当前瓶颈，登记。

## 9. A 门下一路径：联合 QMC / 系统采样 / 判据复核（2026-10-10，NQ 验证后）

### 9.1 NQ 验证事实

- NODE-QMC-1 实测 ~2.3× 改善（512/1024 层：1.695e-2 → 7.269e-3、2.238e-2 → 9.556e-3），**远低于固定节点上界 35×**；2048 层反弹（3.2e-3）。
- 60-day：M=512 时 A/B_opt/B_audit 三项全不过（A 差 72.7×；B_opt=6.58e-6 差 6.6×；B_audit=1.03e-4 差 103×）；**固定节点变体下 B 两项已过（2.79e-8 / 8.97e-7）、仅 A 差 6.5×——A 是最难项**。

### 9.2 2.3× 的由来（静态分析，三因子）

1. **多套独立点列的同索引联合低差异性不足**：当前场景 s 由三套独立 net 的同索引点拼成——opt_rule（d/row）、mu_rule（z1/z2）、node_rule（node）各自低差异，但 (node, z) 的二维投影**不是联合低差异**。mu 对被积函数的贡献强烈依赖节点（每个节点的 mu_hat / ck / S_alpha 都不同），(node, z) 联合结构因此关键；独立拼接使该二维投影的 discrepancy 不受控。
2. **离散化损失**：节点选择是离散 inverse-CDF（阶梯函数，有限变差 K 级）。1 维 QMC 对它有 O(V·logM/M) 界，但常数 ~K（节点数）；且误差对台阶边界位置敏感——这是残余方差的一个来源，但不是主导（否则不会只有 2.3×）。
3. **索引对齐相关性**：三套点列按同一 s 配对，联合分布的 discrepancy 由各序列的伪随机交叉项贡献，无法通过单独优化任一序列消除；2048 层反弹与层间联合结构变化一致。

**结论**：2.3× ≈ 单通道收益被联合结构瓶颈截断；固定节点的 35× 上界包含“节点方差 + 节点-其余通道相互作用”两项，QMC 节点只吃掉了前者的小部分。

### 9.3 候选对比

- **(a) node+z 联合 QMC（推荐主候选）**：mu 通道内部两源用**同一个 2 维 net** 驱动——u_node 取第 1 维、u_z1 取第 2 维（t=330 的 N=1 时 z 恰 1 维，2 维**正好匹配**现有 SobolOwenRule(2)）。无偏/嵌套/确定性/audit 独立全继承（同 seed 重建 + scramble）；实现面小（合并两套 seed 派生为一套，node_pts 删除、mu_pts 的两维重新分配）；预期：直接把 (node, z) 联合纳入低差异控制——这是 9.2 因子 1 的对症修复。**N≥2 的退化**：z 有 2 个主方向 + node = 3 维需求 → 分层方案（node+z1 用联合 2 维，z2 退回 MC）或第二 net——登记待实测。
- **(b) 节点系统采样**：对离散分布的经典方差缩减（分层）。分析：**2 的幂点数下，1 维 scrambled van der Corput（即现有 SobolOwenRule(1)）已在做随机化分层**；非 2 的幂点数的嵌套系统采样需层级细化构造，而同 u 前缀加位截断在 shift 随层变化时不满足前缀嵌套（硬约束）。**结论：b 不提供超出当前 1 维构造的新收益，归约为 a 的组成部分**；不再单列。
- **(c) 全通道联合（node+z+d/row 同一 net）**：需 ≥4 维 → 方向数表来源问题照旧（Joe-Kuo 不可得；凭记忆内联禁止），高维效率亦未证。**登记为风险项，不采用**（除非受控数据交付方向数表）。
- **(d) 判据/证书复核（SPEC 级分析，不预判）**：事实——固定节点下 B_opt/B_audit 已达精度、A 差 6.5×。语义：B 是目标量（二阶于 A：B ≈ H·A²/2），A 是权重一阶量。在**近等价最优集平坦**的弱信号日，w 可在最优集上大幅移动而目标不敏感——A 大而 B 小是**合法形态**（目标稳定但权重不定），此时 A 的残余主要反映**最优集几何**，不全是数值缺陷。D-091 的 tie-break 已处理平局返回哪个点的规范代表问题；**A 是否应作为硬门、抑或 B 为主 + A 作规范代表一致性是 SPEC 级议题**——本设计只登记分析与两候选立场，不实施。

### 9.9 NEST-SYS-1：嵌套系统采样（2026-10-10，NB 扫描后）

- **背景修正**：§9 对系统采样的归约（1 维 scrambled Sobol 已在 2 的幂点上分层）**不准确**。对离散 CDF 的**区间计数**，van der Corput 前缀有经典性质 |N([0,a)) − M a| ≤ 1；而 Sobol(1) 的位矩阵 scramble 只保 dyadic net、一般区间偏差 O(logM) 级。精确频率正是系统采样的优势。
- **构造（NEST-SYS-1）**：shifted van der Corput——x_i = mod(u + vdc32(i-1), 1)，vdc32 = 32 位位反转/2^32（中点插入序：0, 1/2, 1/4, 3/4, 1/8, …）。性质：a) 区间计数 ≤ 2（平移后）；b) 前缀嵌套按构造；c) 加性 shift u（seed 派生、opt/audit 独立）；d) 确定性、任意 M。
- **实现**：gen 的节点驱动从 SobolOwenRule(1) 换为 _nested_systematic_points(_mu_node_shift(rule.seed), M)（_mu_node_rule_seed 保留供 NODE-QMC-1 历史锚测试）。_draw_mu_qmc 5 参不变；默认路径零变化。
- **判据与待验证**：A 序列 1024..8192 重测；判据 = node 通道贡献接近固定节点上界（@1024 应 ≤ ~6.5e-4，理想 1e-4–3e-4）；60-day 三项。
- 层归属：数值工程层（同一积分的采样驱动升级）；无偏/嵌套/确定性语义继承。
- **实施结果与回退（NS 验证）**：NEST-SYS-1 负边际——链在 S=256 层求解崩（SLOW_PROGRESS + 双候选不过；NODE 布局下同层正常）；quadrature/回归全绿、实现按契约工作。已回退到 NODE-QMC-1 驱动；NEST 函数/testset 保留为历史锚（未接线、测试可跑、无副作用）。
- 教训：**节点通道的任何改动都必须同时通过 kelly 求解质量这一关**（采样层的收益不得以求解层退化为代价）。
- A 门最好状态 = NODE-QMC-1（A@8192 = 9.0e-4、末四级收敛、速率 1.46× 递减）。

### 9.10 A 门组合补缺：Chisq-QMC（2026-10-10，深段序列后设计）

**背景（深段全序列，NODE 布局）**：7.269e-3 → 9.556e-3 → 3.197e-3 → 1.310e-3 → 8.996e-4 → 3.694e-4 → 1.053e-4（距门 5.3%）→ 7.193e-4（65536 反弹 6.8×）。NEST/JOINT 负边际（求解敏感）；MC 振荡。

#### 9.10.1 反弹成因分析（候选与可检验预测，不预判）

- 事实：μ 通道中 node（Sobol(1)）与 z1/z2（mu_rule Sobol）已 QMC；**Chisq g（rand(mu_rng, Chisq(nu))）是唯一纯 iid 源**（N=1 时；N>2 时 z 尾部亦是 iid）。
- 机理候选：名义上全部通道“同 seed 重建”满足前缀嵌套；但 iid 序列的前缀**分布不均匀**（就是 iid 样本）——其抽样误差 ~M^{-1/2} 且层间独立。当 QMC 通道的噪声随 M 收缩后，**iid 通道成为主导** → 收敛变慢 + 层间波动（65536 反弹与 iid 噪声形态一致）。
- 可检验预测：
  - P1：Chisq-QMC 化后 65536 反弹消失/显著缓解 → Chisq 为主因；
  - P2：反弹减小但仍在 → 混合（Chisq + z 尾部/opt_rule 残余）；
  - P3：整体速率提升但反弹不变 → Chisq 是速率瓶颈、反弹另有主因；
  - P4（对照）：Chisq 固定会崩（通道分解已证）——QMC 化不等于固定：保持分布、只改分层。

#### 9.10.2 候选

- **(a) Chisq QMC 化（推荐）**：1 维 inverse-CDF（quantile(Chisq(nu), ·)，截尾同 Φ^{-1} 的 ε 处理）；驱动源新建独立 1 维 SobolOwenRule(1, seed)（与 NODE 同构造、已知求解兼容；vdc 备选）。**不触发求解敏感的论证**：与节点改动（NEST/JOINT，改变场景分组结构）不同，Chisq 只改每场景的**尺度因子抽样序列**，不改变任何场景的资产构成/相关性；但重尾 g 的极端值出现模式仍可能影响 scenario 幅度——故实现为**正交独立开关**（mu_chisq_qmc=false 默认），可单独回退。
- **(b) 求解增强**：NEST 案例该层 raw kkt=2.48e-3、scaled 2.89e-4——差两个数量级，非 polish 可救；不放松门禁的前提下无可行的求解增强路径（主求解容差已至 min(tol/10,1e-10)）。**不采用**；M2 出口证书化已保证该情形以 fail-loud 呈现（而非崩溃）。
- **(c) 混合**：NODE + Chisq-QMC（正交开关）+ 深预算扫描。推荐实质 = a 新增、b 不采用。

#### 9.10.3 实现规格（a）

1. 开关与派生：mu_chisq_qmc::Bool=false（仅当 mu_qmc=true 时生效）；_mu_chisq_rule_seed(s) = s ⊻ 新常数。
2. gen：预生成 g_pts = mu_qmc && mu_chisq_qmc ? rule_points(SobolOwenRule(1, _mu_chisq_rule_seed(rule.seed)), M) : Float64[]；调用加 u_g 参数。
3. _draw_mu_qmc：签名加 u_g::Float64；启用时 g = quantile(Chisq(nu), ε_q + (1-2ε_q)·clamp(u_g))（ε_q 命名常量、待 D-066）；禁用时维持 rand(mu_rng, Chisq(nu))（默认路径零变化）。流消费变化仅在开关路径内。
4. 不变量：门槛/证书不动；无偏（scramble 随机化）；嵌套（同 seed 重建）；audit 独立（seed 派生）；确定性。

### 9.11 z1 方差的深层缩减：可行性设计（2026-10-10，深段分解后）

**背景（DS 分解）**：z1 固定 → A 塌缩 7 个数量级（7.193e-4 → 9.477e-11）；z1 是 μ 的建模不确定性（S_alpha 谱 λ1=58.7、share=1.0，**必须保留**——固定它等于假装已知 μ 的建模，语义不允许）；其采样方差是深段振荡底（~1e-4–7e-4，与门同量级）；z1 当前已由 Sobol(1) 驱动（mu_pts 维 1）；chisq 次要（3×）；node 固定深段恶化。

#### 9.11.1 方差率分析

- 任务不是消掉 z1（那是语义错误），而是更高效地积分它。w 对 z1 的映射：z1 经 √λ1（占 μ 最大方向）线性进入 μ，再经 Kelly 解（非线性、在支撑切换处分段光滑）。
- 1 维 QMC 的极限率：对光滑函数，加性 shift 的系统采样/分层误差可到 O(M^{-2})（规则网格 + shift 的中点法则结构）；对分段（支撑切换）函数退化为 O(M^{-1}) 级、常数取决于分段的计数误差。
- 实测底 ~1e-4@32768 高于 1/M 常数的原因候选：(i) 与 d/z2/Chisq/node 的**联合耦合项**不被单维分层控制；(ii) Kelly 解的**支撑切换分段**使误差含 M^{-1} 级项（常数与 z1 驱动序列的区间计数性质相关——Sobol(1) 的位 scramble 只保证 dyadic 分层，任意区间 O(logM)）；(iii) A 是两个不同样本量解的差，非线性放大。

#### 9.11.2 候选

- **(a) z1 换 vdc（推荐）**：用保留的 _nested_systematic_points（任意区间计数 ≤2 的经典性质）替换 mu_pts 维 1 的 Sobol(1) 驱动；维 2（z2）保持不动。**求解敏感风险论证**：z1 是 μ 的**连续幅度维**，改动只平滑地改变每个场景的 μ 值，不改变场景分组/支撑结构（与 NEST 的节点重排不同）——预期风险低于 NEST，但仍须以独立开关（mu_z1_vdc=false 默认）+ S=256 层实测检查（NEST 教训的硬约束）。零新代码（函数已在、测试已在）。
- **(b) z1 求积化（SPEC 议题，登记不实施）**：用确定性求积节点（如 GH）× 其余源抽样的混合结构。完整形态需要**非等权场景**（求积权重进入 Kelly 的 Σ 目标）——触及目标函数与场景语义（数学对象边界），且求积对分段函数不保证无偏；若实施必须走 SPEC 审议。轻量变体（固定 K 个 z1 节点、等权循环分配）虽不破坏嵌套（节点数不随 M 变），但引入 z1 的离散化偏误且收益未证——登记。
- **(c) 联合/更高维**：z1 与 node/d/z2 联合 net——维数超出（方向数表）与求解敏感（JOINT/NEST 教训）双重约束。不推荐。
- **(d) 接受为噪声底**：登记边界——门保持（不放松 weight_tol）；若 a/b 均不成，t=330 类决策日在 32768/65536 级以 fail-loud（D-067）呈现，60-day 链不能以该日收口；这是诚实边界（等待更深预算——但 65536 已反弹——或方法突破）。

#### 9.11.3 实现规格（a）

1. 开关与派生：mu_z1_vdc::Bool=false（仅当 mu_qmc=true 生效）；_mu_z1_shift(s) = rand(MersenneTwister(s ⊻ 新常数))。
2. gen：z1_pts = mu_qmc && mu_z1_vdc ? _nested_systematic_points(_mu_z1_shift(rule.seed), M) : Float64[]；调用处 u_z1 = mu_z1_vdc ? z1_pts[s] : mu_pts[s, 1]（_draw_mu_qmc 签名不变）。
